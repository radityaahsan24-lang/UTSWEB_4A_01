## Deskripsi Singkat
Website ini merupakan profil perusahaan dari "Bale Coffee Sanctuary", sebuah kafe berkonsep ruang terbuka hijau yang rindang dan nyaman (*cozy*). Website ini memiliki 8 bagian utama yang responsif menggunakan Bootstrap 5 dan dilengkapi dengan 4 fitur interaktif manipulasi DOM menggunakan JavaScript.

## Penerapan Manipulasi DOM
1. **Filter Menu Dinamis:** Menyaring item menu (Kopi, Non-Kopi, Makanan) secara langsung tanpa memuat ulang halaman.
2. **Animasi Counter Angka:** Menampilkan angka statistik kafe secara bergerak naik saat halaman dimuat.
3. **Validasi Formulir & Notifikasi Dinamis:** Memvalidasi kolom masukan form reservasi meja dan menyapa nama user secara dinamis pada *alert banner* ketika sukses.
4. **Cozy Mode Toggle:** Mengubah gaya visual seluruh website secara instan dari mode terang (*day mode*) ke mode gelap temaram (*night mode*).
